คำสั่งเริ่มต้นสำหรับเครื่องใหม่

ให้ติดตั้งและตรวจสอบระบบผู้ช่วยจาก Project ปัจจุบันตาม README.md โดยลงมือทำจริง ห้ามใช้ Git ห้ามอ่านหรือเปิดเผย secrets และห้ามแก้ไฟล์นอก Project กับ installation roots ที่คู่มือระบุ

บน macOS Apple Silicon ให้ตรวจ manifest, รัน installer, status, tests, native self-test และ real app-server routing จากนั้นปิด Codex ด้วย Command-Q แล้วเปิดใหม่ ตรวจว่า `✦ Auto` ปรากฏและทุก outbound request ถูกแทนด้วย official model ก่อนถึง real Codex

ห้ามถามหรือตั้งชื่อระหว่างติดตั้ง หลังทุก verification ผ่านและ exit code สำเร็จแล้วเท่านั้น ให้ถามว่า “ต้องการตั้งชื่อผู้ช่วยว่าอะไรคะ?” และรอคำตอบก่อนรัน `./name.sh "ชื่อที่ผู้ใช้ตอบ"`
