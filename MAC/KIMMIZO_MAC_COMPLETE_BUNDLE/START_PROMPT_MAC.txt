โปรดติดตั้ง Kimmizo Auto จากโฟลเดอร์ Project ปัจจุบันให้จบ โดยลงมือทำจริงและรายงานตามหลักฐาน:

0) ก่อนเริ่มติดตั้ง ให้ถามผู้ใช้ว่าต้องการตั้งชื่อเลขาคิมว่าอะไร หากผู้ใช้ไม่ระบุให้ใช้ “เลขาคิม” และส่งชื่อด้วย `./install.sh --name "ชื่อที่ผู้ใช้เลือก"`

1) ยืนยันว่าโฟลเดอร์ปัจจุบันคือ KIMMIZO_MAC_COMPLETE_BUNDLE และระบบเป็น macOS Apple Silicon arm64
2) อ่าน README.md และ STEP_BY_STEP_MAC.md เฉพาะคำแนะนำติดตั้ง ห้ามอ่านหรือคัดลอก credentials, auth files, .env, private keys, tokens หรือประวัติสนทนา
3) รันคำสั่งต่อไปนี้จาก root ของ bundle:
   chmod +x install.sh status.sh uninstall.sh
   ./install.sh
4) หาก installer หา real Codex executable ไม่พบ ให้ค้นหาเฉพาะ executable ชื่อ codex หรือ codex-cli ภายใน /Applications/Codex.app/Contents/Resources แล้วรัน ./install.sh --real-codex '<absolute-path-ที่ตรวจแล้ว>'
5) ห้ามใช้ sudo ห้ามติดตั้ง Homebrew/Go/Python/Node/.NET/Xcode และห้ามแก้ ~/.codex/config.toml
6) เมื่อติดตั้งสำเร็จให้รัน ./status.sh และยืนยัน status=ready, policyVerified=true, voiceVerified=true, realCliExecutable=true, storesPrompts=false, secretsCopied=false และ CODEX_CLI_PATH ชี้ไปยัง ~/.kimmizo-secretary/auto/kimmizo-auto
7) หากขั้นตอนไหนล้มเหลว ให้หยุด รายงาน error จริง และยืนยันว่า rollback สำเร็จ อย่าอ้างว่า PASS
8) เมื่อทุกอย่าง PASS ให้บอกฉันกด Command-Q เพื่อปิด Codex แล้วเปิดใหม่ จากนั้นให้เลือก ✦ Auto และทำ checklist ใน VERIFY_ON_MAC.md ค่ะ
