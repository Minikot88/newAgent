โปรดติดตั้ง skill “คิม” จากโฟลเดอร์ Project ปัจจุบัน โดยลงมือทำจริง

1. ยืนยันว่า current folder คือ KIMMIZO_MAC_COMPLETE_BUNDLE
2. ห้ามใช้หรือสร้าง Git repository
3. ห้ามอ่าน คัดลอก แสดง หรือส่งต่อ secrets, token, private key, password, credentials, auth files หรือไฟล์ .env
4. คัดลอก `skills/kimmizo` ไปที่ `~/.codex/skills/kimmizo` โดยรักษาไฟล์ `SKILL.md`
5. ห้ามแก้ `~/.codex/config.toml` และห้ามตั้ง `CODEX_CLI_PATH`
6. ปิด Codex ด้วย Command-Q แล้วเปิดใหม่
7. ยืนยันว่าใช้เฉพาะโมเดลทางการที่ปรากฏในเมนู Model; ห้ามสร้างหรือเลือก `athena-auto` หรือ `✦ Auto`
8. ทดสอบด้วยข้อความ `คิม ช่วยแนะนำตัวสั้น ๆ` ผลต้องเป็นภาษาไทย เป็นผู้หญิง ใช้ “ฉัน” และลงท้าย “ค่ะ”
9. สรุปผลพร้อม exit code และหลักฐาน โดยไม่เปิดเผยข้อมูลลับ
