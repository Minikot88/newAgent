# Kimmizo Memory

Checkpoint Goal, Boss constraints, Decisions, Files, Tests, Evidence, Blockers, and Next actions. Keep BOOT/current memory at 150 lines or fewer. Context packets are at most 6 sources or 300 lines. Worker returns are at most 10 bullets with pointers instead of raw logs.

Record failures as candidates. Promote a lesson only when Evidence, Root cause, and a Prevention test are present. Ask permission before recording a personal preference. Keep all memory inside this project; no cross-project memory, vector database, or telemetry in v1.
